## 1. 背景与目标

### 1.1 业务背景

抖音创作者在内容全链路中普遍面临四类痛点：

| 痛点 | 表现 | 对应链路 |
|------|------|----------|
| 选题难 | 不知道拍什么、跟热点慢 | 选题 |
| 创作慢 | 脚本结构弱、前 3 秒留不住人 | 创作 |
| 违规风险 | 绝对化用语、行业红线踩坑 | 审核 |
| 复盘无方向 | 有播放无涨粉、不知道改哪里 | 成长 |

抖音创作者中心已提供播放量、完播率、涨粉量、流量来源、分体裁分析等数据能力，但**数据与行动之间缺少 AI 桥梁**。本产品旨在将平台策略与 AI 能力产品化，贯穿 JD 所述全链路：

**选题 → 创作 → 发布 → 审核 → 成长**

### 1.2 产品目标

1. **用户价值**：降低创作者从选题到发布准备的决策与执行成本。
2. **业务价值**：验证「阶段 × 垂类」个性化 AI 机制是否提升平台原生内容指标。
3. **面试/演示价值**：体现 AI 产品运营能力——需求分析、方案设计、指标定义、数据驱动迭代、合规意识。

### 1.3 与岗位的匹配

| JD 要求 | 产品体现 |
|---------|----------|
| 创作者全链路 AI 产品规划 | 五段生命周期工作台 |
| 阶段 × 垂类个性化机制 | 画像驱动选题/脚本/复盘差异化 |
| 数据驱动迭代 | L1 平台指标 + L2 产品指标 + A/B 看板 |
| AI 建议准确度与满意度 | P5 准确率、P6 满意度、采纳反馈 |
| 内容安全与合规 | 发布前合规预检 |
| 需求分析、PRD、原型 | 本文档 + 可交互 WebApp |

## 2. 用户画像与分层策略

### 2.1 目标用户

抖音垂类短视频创作者（个人为主），垂类包括：美食、美妆、知识、剧情、旅行、健身。

### 2.2 创作者分层

| 阶段 | 定义 | 运营重点 | AI 策略差异 |
|------|------|----------|-------------|
| **新手** | 粉丝 &lt; 1 万 | 选题命中率、5 秒完播、发布频次 | 低竞争选题 + 短脚本（25–35 秒） |
| **成长期** | 粉丝 1–50 万 | 人设差异化、系列化、互动转化 | 悬念结构 + 系列预告（45–90 秒） |
| **头部** | 粉丝 50 万+ | 商业转化、IP 延展、合规 | 品牌开场 + 商业植入自然过渡 + 严格合规 |

### 2.3 用户故事

**主流程：**

```
进入工作台 → 设置画像（昵称/阶段/垂类/默认内容目标）
  → 【选题】曝光/种草目标 + 可选商单 Brief → 采纳 1 条
  → 【创作】生成框架 → 三选一钩子 → 分镜结构，复制使用
  → 【合规】标题 + 口播 + 简介预检，修改至通过
  → 【发布】完成检查清单，复制标题/标签，Mock「复制并去抖音发布」
  → 【成长】查看行动建议
  → 【AI 作品诊断】分维度解读（对标同类 + 现状/原因/建议）→ 回到选题（闭环）
```

**辅流程（面试官/运营）：** 总览 → **AI 作品诊断** → 指标看板（漏斗 L1 + L2）→ PRD 页。

## 4. 功能需求详述

### F1 AI 智能选题

**输入：** 创作者阶段、内容垂类  
**输出：** 选题卡片列表（标题、热度、竞争度、匹配分、推荐理由、话题标签、建议体裁/时长）

**规则：**
- 选题库按垂类配置（`TREND_TOPICS`）
- 新手阶段热度/匹配分加权上浮（`stageMultiplier`）
- 竞争度由热度推导：高热度 → 高竞争

**成功标准：** 用户可采纳选题并流转至创作页。

---

### F2 AI 脚本助手

**输入：** 已选选题 + 创作者画像  
**输出：** `ScriptOutline`（hook、structure[]、cta、duration、tips[]）

**规则：**
- 钩子模板按垂类差异化（美食/美妆/知识等）
- 分镜结构按阶段差异化（新手 4 段短结构 vs 头部深度结构）
- 未选题时展示引导，禁止空生成

**关联 L1 指标：** 5 秒完播率、2 秒跳出率、完播率（脚本质量代理）

---

### F3 发布助手

**输入：** 选题、画像  
**输出：** ≥5 项检查清单、建议发布时段、标题与标签草稿（可复制）

**规则：**
- 清单未全部勾选时提示警告
- 发布时段按垂类 mock（抖音垂类高峰统计思路）

**关联 L1 指标：** 投稿数、发布后 1h 播放量

---

### F4 合规预检

**输入：** 用户粘贴的标题/口播/描述文案  
**输出：** 合规分、风险项（高/中/低）、修改建议、是否通过

**规则：**
- 敏感词子串匹配 + 绝对化词加权扣分
- 存在「高」风险项且分数 &lt; 70 不通过
- 固定建议：免责声明、#广告 标注、避免标题党

**关联指标：** 违规驳回率下降（A/B 护栏）

---

### F5 成长复盘

**输入：** 创作者画像 + mock 账号数据  
**输出：** ≥3 条可执行建议（含阶段差异化 tip）

**关联 L1 指标：** 涨粉量/粉丝净增量、互动指数

---

### F6 指标看板

展示双层指标体系、趋势图、A/B 实验、分功能采纳率。详见第 6 章。

---

### F7 PRD 展示页

应用内只读摘要 + 链接 `docs/PRD.md` 完整版。

## 6. 核心指标体系（V2）

> **设计原则：** L1 按**抖音作品数据详情**四段漏斗组织；**AI 诊断交互**借鉴小红书「笔记诊断」；L2 验证工具与诊断是否有效。二者不可混用。

### 6.1 指标逻辑链

```
选题/脚本/发布/合规（创灵 AI）
  → 发布作品
    → L1 抖音漏斗指标变化（按段观测）
      → F5+ 分维度 AI 诊断（对标同类 + 建议）
        → 反哺 L2（P5 诊断有效率、P6 满意度）
          → A/B 迭代（如钩子 → 5秒完播）
```

### 6.2 L1：抖音作品数据详情（主参考 · 四段漏斗）

> **来源：** 抖音创作者中心 → 作品数据详情 → **总览**（与你提供的后台截图一致）。  
> **辅助 Tab：** 流量分析、内容分析、观众分析（V1.2 深化）。

#### 第 1 段：流量转化

| 指标 | 口径 | 创灵 |
|------|------|------|
| 曝光量 | 作品展示次数 | F6 看板 |
| 播放量 | 观看次数 | 规模基线 |
| 封面点击率 | 播放÷曝光 | F3 标题/封面、F5+ 诊断 |
| 粉丝占比 | 各指标中粉丝贡献% | 是否只吃老粉 |

**段内提示：** 优化封面标题，提升观看转化。

#### 第 2 段：开头吸引力

| 指标 | 口径 | 创灵 |
|------|------|------|
| 2 秒退出率 | 2 秒内划走占比 | 钩子失败信号 |
| 5 秒完播率 | 前 5 秒留存 | **F2 脚本核心验证** |
| 粉丝占比 | 同上 | 老粉是否看完开头 |

**段内提示：** 把握视频节奏，留下更多观众。

#### 第 3 段：互动表现

| 指标 | 口径 | 创灵 |
|------|------|------|
| 互动率 | 平台展示口径 | 共鸣程度 |
| 点赞/评论/弹幕/收藏/分享 | 分项 | 缺哪类互动 |
| 粉丝占比 | 分项粉丝贡献 | 互动是否靠铁粉 |

**段内提示：** 创造互动场景，引发观众互动。

#### 第 4 段：内容深度

| 指标 | 口径 | 创灵 |
|------|------|------|
| 平均观看时长 | 秒 | 中段拖沓 |
| 60 秒播放数 | ≥60s 人数 | 中长视频 |
| 全片完播率 | 完播÷播放 | 深度质量 |
| 涨粉数 | 本条带来粉丝 | **P4 成长转化** |

**段内提示：** 增加内容价值，带来更多涨粉。

#### 其他 Tab（作品级）

| Tab | 关键指标 | V2 演示 |
|-----|----------|---------|
| 流量分析 | 推荐/搜索/关注/同城占比；渠道漏斗 | F5+ Mock |
| 内容分析 | 留存曲线、掉点、弹幕趋势 | V1.2 |
| 观众分析 | 性别/年龄/城市/新老用户/活跃度 | F5+ 一句洞察 Mock |

**业务理解：** 推荐重「留得住」>「点得来」。高播放+低完播要联动诊断第 1 段 CTR 与第 4 段完播（借鉴小红书「高曝低完播」护栏）。

### 6.3 小红书「笔记诊断」借鉴（交互机制 · 非替代抖音口径）

> **来源：** 小红书创作者中心 → 笔记数据详情 → 笔记诊断 / 指标解读 AI。  
> **创灵做法：** 指标用抖音，**产品形态学小红书**。

| XHS 机制 | 创灵 F5+ 对应 |
|----------|----------------|
| 五维雷达 + 同类对比 | 四段漏斗雷达（4 维得分 Mock） |
| 维度状态「较好/待提升」 | 绿/橙标签 |
| 同类中位数、超过同类% | 每条诊断展示 |
| **现状 → 原因分析 → 建议** | 分维度弹窗三段式 |
| 流量分析「开始诊断」 | 诊断页主按钮 |
| 24h 后可重新诊断 | 文案 Mock |

**不单列小红书 KPI**；仅 CTR 护栏、诊断叙事结构借鉴。

### 6.4 P3 内容质量综合分（公式与权重原理）

> 支撑 **JD「内容质量」**；输入为 L1 归一化后的分项，输出 0–100 分。

**计算公式：**

```
P3 质量分 =
  norm(5秒完播率) × 35%
+ norm(全片完播率) × 30%
+ norm(互动率)     × 20%
+ norm(封面点击率) × 15%
```

**归一化：** `norm(x) = (x - P25同类) / (P75同类 - P25同类) × 100`，截断至 [0,100]。

| 权重 | 指标 | 参考来源 | 权重原理 |
|------|------|----------|----------|
| **35%** | 5秒完播率 | 抖音 §开头吸引力 | 冷启动最先验证；绑定 F2 钩子，权重最高 |
| **30%** | 全片完播率 | 抖音 §内容深度 | 决定更高流量池；反映中段节奏与信息密度 |
| **20%** | 互动率 | 抖音 §互动表现 | JD 含互动；防刷量故低于完播 |
| **15%** | 封面点击率 | 抖音 §流量转化 | 入口效率；权重最低，且须与完播联动防标题党 |

**目标：** 采纳 AI 建议的作品 P3 ≥ **70 分**。

## 7. 验收标准

## 11. 附录

### 11.1 抖音指标 vs 小红书诊断形态

| 能力 | 抖音（指标口径） | 小红书（产品形态借鉴） |
|------|------------------|------------------------|
| 漏斗结构 | 作品详情四段 | 笔记概览四段（同名） |
| 对标 | 同类创作者中位数 | 同类笔记中位数 |
| AI 输出 | V2 创灵补齐 | 现状/原因/建议弹窗 |
| 雷达 | 分维度得分 | 五维雷达 |
| 护栏 | CTR+完播联动 | 高曝低完播经验 |

### 11.2 面试演示脚本（3 分钟 · V2）

1. **痛点（20s）：** 有数据不会改——创作者中心有漏斗，缺 AI 把数翻译成行动。  
2. **方案（40s）：** 创灵：抖音口径 + 小红书式诊断；全链路 + P3 公式有权重原理。  
3. **Demo（90s）：** 选题→脚本→合规→**AI 作品诊断**（开始诊断、点「开头吸引力」看 AI 解读）→指标页看四段漏斗与 P3。  
4. **数据（40s）：** P3=5秒35%+完播30%+互动20%+CTR15%；P5 诊断有效率。  
5. **迭代（30s）：** V1.1 真 LLM；V1.2 接抖音开放平台。
