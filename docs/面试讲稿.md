# 创灵 · 面试讲稿（GitHub Pages + Mock 版）

> 配合在线 Demo 使用，约 3 分钟。

---

## 一、开场（20 秒）

我做了一个面向抖音创作者的 AI 运营工作台 **「创灵」**，覆盖岗位 JD 里的全链路：**选题 → 创作 → 发布 → 合规 → 成长**。

在线 Demo：https://aurora132731.github.io/douyin-creator-ai/  
代码与 PRD：https://github.com/aurora132731/douyin-creator-ai

---

## 二、痛点与方案（40 秒）

创作者常见四类痛：**选题难、写得慢、怕违规、复盘无方向**。

创灵用 **阶段 × 垂类** 做个性化。当前是 **MVP**：规则引擎模拟 AI + Mock 数据，先验证链路和指标；真大模型在 V1.1，抖音数据在 V1.2。

---

## 三、现场演示路径（90 秒）

1. **工作台总览** → 点「开始演示」
2. **改画像** → **AI 选题** → 采纳一条
3. **AI 创作** → 展示钩子、分镜
4. **合规预检** → 点「违规样例」
5. **数据指标** → L1 平台 + L2 产品 P1–P6
6. **产品方案** → PRD 摘要

---

## 四、指标（40 秒）

| 层级 | 例子 |
|------|------|
| **L1** | 5 秒完播、完播率、涨粉（抖音创作者中心口径） |
| **L2** | 留存、效率、质量分、AI 准确率（对齐 JD） |

---

## 五、收尾（30 秒）

- **V1.0**：GitHub Pages + Mock  
- **V1.1**：接豆包/通义  
- **V1.2**：抖音开放平台数据  

练习项目，非字节官方产品。

## 六、高频追问

**Q：为什么不用真 AI？**  
A：优先验证需求、链路和指标口径；真 API 在 V1.1。

**Q：数据是真的吗？**  
A：数值 Mock，口径对齐抖音/小红书/快手及 JD。

**Q：和创作者中心的区别？**  
A：中心给数据；创灵加 AI 建议层（选题、脚本、合规、复盘）。
