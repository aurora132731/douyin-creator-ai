## 一、3 分钟口播（连贯版 · 建议背）

**【0:00–0:20 开场】**  
您好，我带来练习项目 **「创灵」**——抖音创作者 AI 运营工作台，对应岗位 **创作者全链路**：选题、创作、合规、发布、成长，以及 **AI 作品诊断**。  
在线 Demo：https://aurora132731.github.io/douyin-creator-ai/ ，PRD 在 GitHub 仓库。

**【0:20–1:00 痛点 + 方案】**  
创作者四类痛：选题难、写得慢、怕违规、**有数据不知道改哪里**。  
抖音创作者中心已有 **作品数据详情**（四段漏斗），但数据和行动之间缺 AI。  
「创灵」把平台策略产品化：**阶段 × 垂类 × 内容目标（曝光/种草）** 差异化；诊断交互借鉴 **小红书笔记诊断**——同类对标、现状/原因/建议，指标口径以 **抖音** 为准。

**【1:00–2:30 演示】**  
我走主流程：画像 → 选题（可选商单 Brief）→ 创作（三钩子选一）→ **合规** → 发布 → **AI 作品诊断** → 指标页。（具体操作见第二节。）

**【2:30–3:00 指标 + 收尾】**  
**L1** 按抖音四段漏斗：流量转化、开头吸引力、互动、内容深度。  
**L2** 对齐 JD：留存、效率、**P3 内容质量分**（5秒完播 35% + 全片完播 30% + 互动 20% + 点击率 15%）、**P5 AI 诊断有效率**。  
下半区 **A/B 实验**用 **抖音内容指标当裁判**——例如钩子实验看 5 秒完播，标题实验 CTR 为主、完播为护栏，避免标题党。  
当前 MVP：GitHub Pages + Mock（数值演示、机制真实）；V1.1 大模型，V1.2 抖音开放平台。个人练习项目，非官方。谢谢。

## 二、演示操作脚本（边点边说 · 约 3 分钟）

| 步骤 | 点哪里 | 你说什么 |
|:----:|--------|----------|
| 1 | 总览 → **「开始演示」** | 工作台覆盖 JD 五段链路 + AI 诊断。 |
| 2 | 顶部改 **阶段 / 垂类 / 默认内容目标** | 推荐会随画像变，阶段×垂类×目标机制。 |
| 3 | **AI 选题** → 选曝光或种草 → 可选开 **商单 Brief** → **采纳一条** | 解决选题难；商单时前几条带合作标签。 |
| 4 | **AI 创作** → **生成框架** → **三选一钩子** | 钩子对应抖音 **§2 五秒完播**；V1.0 是模板框架。 |
| 5 | **合规预检** → **「加载违规样例」** | 标题+口播+简介；JD 内容安全；**必点，效果最好**。 |
| 6 | **发布助手** → 勾选清单 → **「复制并去抖音发布」** | 合规后再发布；清单 + 标题标签 Mock 去抖音。 |
| 7 | **AI 作品诊断** → 选 **一篇已发布作品** → **「开始 AI 诊断」** | 先雷达看基础数据，再生成解读（按钮约 1–2 分钟态）。 |

| 10 | **产品方案** | PRD V2 摘要 + 未来迭代方向。 |

- 第 5 步务必点「违规样例」（合规在发布**之前**）  
- 第 7–8 步是 V2 亮点，停留约 30 秒  
- 第 9 步指标页停 **30 秒**：先 P3 权重，再 **EXP-01（5秒完播）** 和 **EXP-05（护栏）**

## 四、指标页怎么讲（指标 Tab 专用）

### 4.1 L1 / L2 / P3（约 20 秒）

| 层级 | 答什么 | 举例 |
|------|--------|------|
| **L1** | 内容有没有变好 | 抖音作品详情 **四段漏斗** |
| **L2** | 工具要不要迭代 | P1 留存、P2 效率、P3、P4 涨粉、**P5 诊断有效率**、P6 满意度 |

**P3 一句话（必背）：**  
5秒完播 **35%** + 全片完播 **30%** + 互动 **20%** + 封面点击率 **15%**。

**AI 诊断一句话：**  
指标用抖音，形态学小红书——同类中位数对标，**现状→原因→建议**。

---

### 4.2 A/B 实验（约 40 秒 · 必讲）

> 页标题：**「A/B 实验（抖音指标当裁判）」** —— 意思是：改产品不能只看按钮点击率，要用 **抖音内容结果指标** 判断哪版更好。右边 **+X%** 是实验组相对对照组的提升（Demo 为 Mock 数值，**机制是真的**）。

**口播模板（可照着说）：**

> 下半区是 A/B 看板。原则是：**用平台内容指标验收产品改动。**  
> 钩子实验对比痛点型和悬念型，主指标是 **5 秒完播**；选题实验看 **采纳率到 7 日播放**；合规实验看 **违规限流率下降**；标题实验主看 **CTR**，但设 **全片完播护栏**，防止标题党。上线后会做真实分流和显著性检验。

| 实验 | A vs B | 主指标（裁判） | +X% 含义 | 对应功能 |
|------|--------|----------------|----------|----------|
| **EXP-01** | 痛点型 vs 悬念型钩子 | **5 秒完播率**（抖音） | 悬念型完播更高 | F2 创作 |
| **EXP-02** | 卡片 vs 列表选题 | 采纳率 → **7 日播放** | 卡片组整条链路更好 | F1 选题 |
| **EXP-04** | 无预检 vs AI 预检 | **违规/限流率↓** | 风险更少 | F4 合规 |
| **EXP-05** | AI 标题 vs 自拟 | **CTR**；**护栏：完播率** | CTR 升且完播未崩 | F3 发布 |

**三个词记住：**

| 词 | 含义 |
|----|------|
| **主指标** | 判断谁赢的唯一标准（必须反映内容结果） |
| **相对提升** | B 比 A 主指标好多少（如 +12.4%） |
| **护栏指标** | 主指标不能靠牺牲体验换（如 CTR↑ 但完播↓ = 标题党，不能上线） |

**被问「数据真的吗？」：**  
数值是 Mock；实验设计、指标选型对齐抖音创作者中心；上线接分流 + 7 日回流，回写 P5。

## 五、高频追问

| 问题 | 答法 |
|------|------|
| 为什么不用真 AI？ | MVP 验证链路与指标；V1.1 接豆包/通义。 |
| 数据真的吗？ | 数值 Mock；**结构**同抖音后台四段漏斗；诊断交互学小红书。 |
| 和创作者中心区别？ | 中心给数；创灵加 **AI 建议层** + 分维度诊断。 |
| 怎么证明 AI 有效？ | **P5**：采纳建议后维度优于同类中位数；**A/B** 用 5 秒完播/CTR 等 L1 验收。 |
| A/B 什么意思？ | 两版方案对比；**抖音指标当裁判**；EXP-05 有完播护栏防标题党。 |
| 为什么叫抖音指标当裁判？ | 创作者最终要看完播、播放、违规，不能只看 App 内点击率。 |
| P3 权重怎么定的？ | 开头 35%（冷启动）、完播 30%（流量池）、互动 20%、CTR 15%（入口且防标题党）。 |
| 合规能上线吗？ | 辅助预检，非法务终审；平台上传后还有视频审核。 |
| 为什么 Mock？ | 一天可演示；机制验证后再接 API。 |
| 曝光和种草区别？ | 曝光偏破圈钩子；种草偏信任/转化结构；商单 Brief 驱动卖点选题。 |
