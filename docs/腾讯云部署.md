## 二、开通静态网站托管（首次约 5 分钟）

1. 打开 **[云开发控制台](https://console.cloud.tencent.com/tcb)**  
2. 使用微信/QQ 登录，完成 **实名认证**（未实名无法开通）  
3. 点击 **「新建环境」**  
   - 环境名称：随意，如 `chuangling-demo`  
   - 按量计费即可（静态托管有免费额度）  
4. 进入该环境 → 左侧 **「静态网站托管」**（或「网站托管」）  
5. 若提示开通，点击 **「开通静态网站托管」**

---

## 三、上传网站（推荐：上传文件夹）

### 方式 A：上传文件夹（最简单）

1. 在静态网站托管页，点 **「文件管理」** 或 **「上传文件夹」**  
2. 选择本地文件夹：  
   ```
   c:\Users\aurora\Documents\抖音项目\app\dist
   ```  
3. **重要：** 确保上传后**根目录**直接是：
   - `index.html`
   - `favicon.svg`
   - `assets/` 文件夹  

   ❌ 错误：根目录变成 `dist/index.html`（多一层 dist 会 404）  
4. 上传完成后，点 **「基础配置」** 或页面顶部查看 **默认域名**

### 方式 B：上传 ZIP

1. 点 **「新建部署」** → **「上传代码包」**  
2. 选择 `release/chuangling-web.zip`  
3. 配置：
   - 安装命令：**留空**
   - 构建命令：**留空**
   - 构建产物目录：**`.`**（解压后根目录即有 index.html）
   - 部署路径：**`/`**

## 四、获取访问链接

上传成功后，在 **静态网站托管 → 基础配置** 中复制 **默认访问域名**，形如：

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 打开是空白页 | 检查是否多上传了一层 `dist` 文件夹；`index.html` 必须在根目录 |
| 刷新子路径 404 | SPA 需在控制台配置「索引文档」为 `index.html`，错误文档也填 `index.html` |
| 样式/JS 加载失败 | 项目已用 `base: './'`，重新 `npm run build` 后再上传 |
| 找不到静态托管 | 确认进的是 **云开发 TCB** 环境，不是 CVM 服务器 |
