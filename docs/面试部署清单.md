## 六、常见问题

| 问题 | 处理 |
|------|------|
| Pages 打不开 | 看 Actions 是否失败；国内慢可本地 `npm run dev` 共享屏幕 |
| Actions 红 | 点进日志看 build 错误 |
| `npm` 找不到 | 重装 Node，或 `$env:Path += ";C:\Program Files\nodejs"` |
