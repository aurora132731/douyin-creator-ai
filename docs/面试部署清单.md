## 考前勾选（按顺序打 ✓）

### 1. 环境

- [ ] 已装 [Node.js LTS](https://nodejs.org/)（`node -v`、`npm -v` 有输出）
- [ ] 已装 [Git](https://git-scm.com/download/win)（`git -v` 有输出）
- [ ] 若终端找不到 npm：`$env:Path += ";C:\Program Files\nodejs"`

### 2. 本地自测（约 10 分钟）

```powershell
cd "c:\Users\aurora\Documents\抖音项目\app"
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`，走通：

- [ ] 改画像（阶段 / 垂类）
- [ ] AI 选题 → 采纳一条
- [ ] AI 创作 → 生成脚本
- [ ] 发布助手 → 勾选清单
- [ ] 合规预检 → 点「违规样例」
- [ ] 数据指标（L1 + L2）
- [ ] 产品方案页能打开

### 3. GitHub 代码（约 2 分钟）

```powershell
cd "c:\Users\aurora\Documents\抖音项目"
git add .
git commit -m "update"   # 有改动才需要
git push github main
```

- [ ] 推送成功（或提示 Everything up-to-date）
- [ ] 仓库最新：https://github.com/aurora132731/douyin-creator-ai

### 4. GitHub Pages（首次只做一次）

1. 打开 [Pages 设置](https://github.com/aurora132731/douyin-creator-ai/settings/pages)
2. **Source** → 选 **GitHub Actions**
3. 打开 [Actions](https://github.com/aurora132731/douyin-creator-ai/actions)，等 **Deploy GitHub Pages** 绿勾 ✅

每次 `git push github main` 后会自动重新部署（约 1～2 分钟）。

### 5. 在线 Demo

- [ ] 电脑能打开：https://aurora132731.github.io/douyin-creator-ai/
- [ ] 手机试开一次（国内可能略慢）
- [ ] 再走一遍：总览 → 选题 → 脚本 → 合规 → 指标

### 6. 面试材料

## 常见问题

| 情况 | 处理 |
|------|------|
| Pages 打不开 / 白屏 | Settings → Pages 是否为 GitHub Actions；Actions 是否失败 |
| Actions 红色失败 | 点进日志，看 `app` 下 `npm run build` 报错 |
| 推送 GitHub 失败 | 检查网络 / VPN；稍后重试 `git push github main` |
| 国内打开很慢 | 面试用本地 `npm run dev` 演示，口头说明 Pages 为备用链接 |
| 改了代码线上没变 | push 后等 Actions 跑完再刷新 |
