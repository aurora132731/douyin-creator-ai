# 面试前 1 天 · Gitee Pages + Mock 清单

> 目标：明天面试前，面试官能打开链接、自己点通全流程。  
> 方案：**不接真 API**，用现有 Mock + 规则引擎即可。

---

## 一、环境准备（约 15 分钟）

- [ ] 安装 [Node.js LTS](https://nodejs.org/)（装完重启终端）
- [ ] 安装 [Git](https://git-scm.com/download/win)
- [ ] 注册 [Gitee](https://gitee.com) 并完成 **实名认证**（开 Pages 需要）
- [ ] （推荐）配置 Gitee **SSH 公钥**：设置 → SSH 公钥

终端检查：

```powershell
node -v
npm -v
git -v
```

---

## 二、本地跑通（约 10 分钟）

```powershell
cd "c:\Users\aurora\Documents\抖音项目\app"
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`，自测：

- [ ] 改画像（阶段 / 垂类）
- [ ] 选题 → 采用一条
- [ ] 创作 → 生成脚本
- [ ] 发布 → 勾选清单
- [ ] 合规 → 输入含「最好」的文案，看到风险提示
- [ ] 成长 → 有建议
- [ ] 指标 → L1 + L2 + A/B
- [ ] PRD 页能打开

---

## 三、推代码到 Gitee（约 15 分钟）

1. Gitee 新建 **公开** 仓库，英文名如 `douyin-creator-ai`，**不要**勾选初始化 README  
2. 记下地址：`git@gitee.com:你的用户名/douyin-creator-ai.git`

```powershell
cd "c:\Users\aurora\Documents\抖音项目"
git init
git add .
git commit -m "feat: 创灵 MVP - 面试演示版"
git branch -M main
git remote add origin git@gitee.com:你的用户名/douyin-creator-ai.git
git push -u origin main
```

---

## 四、部署 Gitee Pages（约 15 分钟）

```powershell
cd "c:\Users\aurora\Documents\抖音项目"
.\scripts\deploy-gitee.ps1 -GiteeUrl "git@gitee.com:你的用户名/douyin-creator-ai.git"
```

网页操作：

1. 仓库 → **服务** → **Gitee Pages**
2. 分支：**gh-pages**，目录：**/**
3. 点击 **启动** 或 **更新**
4. 等待 1～3 分钟

- [ ] 用手机 + 电脑各打开一次：`https://你的用户名.gitee.io/douyin-creator-ai/`
- [ ] 若白屏，在 `app` 下执行后重新部署：
  ```powershell
  $env:VITE_BASE_PATH="/douyin-creator-ai/"
  npm run build
  ```
  再跑一遍 deploy 脚本

## 七、常见问题

| 问题 | 处理 |
|------|------|
| `npm` 找不到 | 重装 Node，重启终端 |
| Pages 没有入口 | 确认已实名、仓库公开 |
| 面试官打不开 | 发仓库链接 + 30 秒录屏备用 |
| 被问为什么不用真 AI | 「1 天 MVP 验证链路与指标；真 AI 在 V1.1，数据在 V1.2」 |
